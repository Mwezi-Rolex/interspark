# Interspark - Equitable Internship Platform

Interspark is a web-based platform designed to bridge the gap between low-income students and internship opportunities by securing stipend-based positions. It addresses the financial barriers that prevent talented students from accepting unpaid internships.

### Core Features
* **Stipend Management:** Integrated system for sponsors (NGOs/Government) to contribute funds, ensuring interns receive support for food and transport.
* **Application Tracking:** Real-time dashboard for students to track application status (Submitted, Under Review, Shortlisted).
* **Role-Based Access:** Distinct portals for Students, Employers, Sponsors, and Admins.
* **Transparency:** Automated notifications for deadlines and application updates to reduce uncertainty.

### System Architecture
The system follows a Model-View-Controller (MVC) architecture to separate concerns and ensure scalability.

**Key Workflows:**
1.  **Sponsorship Flow:** Sponsors register -> Submit funding application -> Admin approves -> Funds allocated to student stipends.
2.  **Application Flow:** Student applies -> Employer reviews -> Schedule Interview -> Hire/Reject.

### Tech Stack
* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **Design:** Figma (Wireframes & Prototypes)
